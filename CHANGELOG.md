# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-16

### Added
- Initial release of SEO Reporter Action
- Integration with seo-reporter npm package (v1.1.2)
- Support for configurable crawl depth, max pages, and concurrency
- Automatic upload of HTML and CSV reports as GitHub Actions artifacts
- Webhook support for completion notifications (GET/POST)
- Comprehensive documentation and usage examples
- Example workflow files for common use cases
- Post-Vercel deployment integration support

### Features
- 220+ SEO checks including metadata, content, links, images, security, and technical analysis
- Interactive HTML reports with filterable issues
- CSV export for further analysis
- Configurable output directory
- Full control over crawling parameters
